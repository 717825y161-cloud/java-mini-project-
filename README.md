# java-mini-project-
Online Auction & Bidding

Problem Statement: Design and implement a Java console application for an Online Auction
system that manages items, sellers, bidders, bids, auctions, and settlements. The application should
demonstrate object-oriented principles and enforce bidding rules.

**HOW TO COMPLILE AND RUN:**
Open Eclipse IDE.
Click File → New → Java Project.
Enter the project name: OnlineAuctionSystem.
Click Finish.
Right-click the src folder → New → Class.
Enter the class name: OnlineAuctionSystem.
Click Finish.
Paste the complete Java code I provided earlier.
Press Ctrl + S to save.
Right-click the file → Run As → Java Application.
